## 3. LoRa

Частотный план RU868 утвержден. Полевая передача остается заблокированной до аппаратного RF PASS и индивидуального EOL PASS. Для измерений в приложении есть ограниченный по времени режим, который применяется только с нагрузкой 50 Ом или в экранированной оснастке.

После утверждения испытаний подписанный полевой профиль устанавливается через приложение. Повторная прошивка не требуется.

## 4. Защита прошивки

Блокировка прошивки, RDP Level 2, окончательная блокировка SWD и необратимые option bytes запрещены. Они могут рассматриваться только после полного аппаратного PASS, регрессии, проверки восстановления и индивидуального EOL PASS каждой станции.

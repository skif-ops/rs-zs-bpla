# Метрики приёмки и слепые зоны расстановки (решение 5, 2026-10-01)

Как по журналам испытаний посчитать то, что «Звук» указывает в своих ТТХ (вероятность обнаружения, доля ложных,
дальность по классам, сектор угла места, минимальный уровень), и точность пеленга и точек трека Дионеи. Расчёт —
`server/station/acceptance.py`, запуск — `server/tools/acceptance_metrics.py`. Слепые зоны геометрии считает
`server/station/geometry_coverage.py`, на странице «Сопровождение» они включаются флажком.

## 1. Что нужно от испытаний

1. Сервер «Мухоед» во время испытаний: база событий (`data/zs_bpla.sqlite3`) с обнаружениями, пеленгами,
   общими треками и (по желанию) аудио, загруженным командой `CMD_REQUEST_AUDIO`.
2. Файл истины `dioneya.trial/1` (JSON), пример ниже: окно испытаний, станции, проходы целей с журналом GNSS цели,
   тихие периоды и исключения. По желанию — показания эталонного шумомера у станций.
3. Для уровня по записи станции — калибровка тракта: запись станцией калибратора 94 дБ SPL на входе микрофона.

```json
{
  "format": "dioneya.trial/1",
  "name": "Полигон, 14.10.2026",
  "window": {"since": "2026-10-14T06:00:00Z", "until": "2026-10-14T12:00:00Z"},
  "stations": [
    {"station_id": 17, "lat": 55.1234567, "lon": 37.1234567, "alt_msl_m": 152.0},
    {"station_id": 18, "operating": [{"since": "2026-10-14T06:30:00Z", "until": "2026-10-14T12:00:00Z"}]}
  ],
  "passes": [
    {"pass_id": "P01", "class": "PISTON_UAV", "note": "заход с севера, 120 м", "track_csv": "p01.csv"},
    {"pass_id": "H01", "class": "HELICOPTER", "track": [{"time": "2026-10-14T08:00:00Z", "lat": 55.2, "lon": 37.1, "alt_msl_m": 400}, "..."]}
  ],
  "quiet": [{"since": "2026-10-14T11:00:00Z", "until": "2026-10-14T12:00:00Z"}],
  "exclude": [{"since": "2026-10-14T09:12:00Z", "until": "2026-10-14T09:20:00Z", "station_id": 17, "note": "трактор у станции"}],
  "levels_csv": "levels.csv"
}
```

- Время — ISO 8601 с `Z` или смещением, либо целое число микросекунд UTC. Время без зоны отвергается.
- Станция без координат берёт их из базы (детекция, иначе heartbeat). `operating` — когда станция работала (по
  умолчанию всё окно).
- Класс прохода — имя класса станции: `PISTON_UAV`, `REACTIVE_UAV`, `ELECTRIC_UAV`, `AIRCRAFT`, `HELICOPTER`,
  `ROAD_TRAFFIC`, …
- Трек — точки `time, lat, lon, alt_msl_m` (CSV с заголовком или список в JSON), между ними — линейная интерполяция.
  Нужен журнал автопилота или GNSS-логгер на цели: шаг 1 с или чаще.
- `quiet` — периоды, когда целей заведомо не было (контроль ложных тревог). `exclude` — интервалы, которые не
  считаются (посторонний источник у станции, обслуживание); без `station_id` — для всех станций.
- `levels` / `levels_csv` — показания шумомера: `station_id, time, spl_db`.

## 2. Как считается

Звук приходит с опозданием: отметку станции в момент прихода ta сравниваем с целью в момент излучения te,
где ta = te + дальность(te) / 343 м/с.

| Метрика | Определение |
|---|---|
| Возможность обнаружения | пара «станция — проход», где цель подходила к работающей станции ближе `max_range_m` (по умолчанию 3000 м; наклонная дальность) |
| Отметка прохода | обнаружение или пеленг станции, для которых цель была ближе `assoc_range_m` в момент излучения (до 5 с за концами журнала — по крайней точке) |
| Pd | доля возможностей с хотя бы одной отметкой; 95 % доверительный интервал Уилсона. Отдельно по классам, по дальности наибольшего сближения и по наибольшему углу места прохода |
| Дальность обнаружения | дальность цели в момент излучения звука первой отметки (медиана, 10 и 90 %, максимум) |
| Дальность при Pd ≥ 0,8 | наибольшая граница интервала дальности, до которой Pd среди пар с меньшим сближением не ниже порога |
| Верный класс | класс первой детекции станции в проходе и класс большинства её детекций против класса прохода; таблица ошибок классов |
| Ложная тревога | детекции, не отнесённые ни к одному проходу; детекции одной станции с промежутком меньше 60 с — один эпизод. Частота — эпизоды на станцио-час работы (без исключённого времени); доля ложных — эпизоды / (эпизоды + обнаруженные пары). Отдельно — в тихие периоды |
| Сектор угла места | углы места цели у отметок (от и до) и Pd по наибольшему углу места прохода |
| Точность пеленга | все пеленги потока (аддендум H) и DOA детекций с доверенным временем (ошибка времени не больше 200 мс) против направления на цель в момент излучения: средняя абсолютная, СКО, медиана, 90 %, смещение; угол места — СКО; доля ошибок в пределах сигмы, заявленной станцией (у честной сигмы около 0,68); то же по углу места цели |
| Точки трека | точки общего трека (время излучения) против цели в то же время: ошибка по горизонтали и вертикали; доля в пределах заявленной ошибки; точки дальше 1000 м от любой цели — ложные |
| Уровень | по шумомеру — SPL у станции в момент первой отметки и Pd по наибольшему SPL прохода; по записи станции — уровень секунды вокруг момента детекции: дБFS (синус полной шкалы — 0 дБFS), а с калибровкой — дБ SPL без взвешивания = дБFS − калибровка + 94 |
| Геометрия | доля времени каждого прохода, когда расстановка даёт точку, слепую геометрию, одну станцию; доля площади вокруг станций для измеренной дальности |

Уровень по записи — это уровень принятого звука (цель плюс фон) в момент обнаружения, а не порог чувствительности.
Минимальный уровень обнаружения дают самые слабые обнаруженные проходы; для честного порога нужен шумомер и
проходы, которые станция не услышала.

## 3. Запуск

```
cd server
python tools/acceptance_metrics.py calibrate --wav cal94.wav           # -> --audio-cal-dbfs -31.8
python tools/acceptance_metrics.py report --db data/zs_bpla.sqlite3 --trial trials/2026-10-14/trial.json \
    --audio-cal-dbfs -31.8 --json report.json --md report.md
```

Параметры `--max-range`, `--assoc-range`, `--pd-threshold`, `--sigma-deg` (сигма пеленга для геометрии; по умолчанию
медиана пеленгов испытаний). `report.json` — все числа и разбор по каждой паре «станция — проход» (`station_passes`),
`report.md` — отчёт для протокола.

## 4. Слепые зоны расстановки

Для цели на высоте `height_m` над станциями в каждой клетке сетки вокруг них — по правилам слияния пеленгов
(`fusion/bearing_fusion.py`):

- станция слышит цель ближе `range_m` (дальность класса, например «дальность при Pd ≥ 0,8» из отчёта);
- точка есть, когда слышат хотя бы две станции, лучи пересекаются под углом не меньше 10° и ошибка не больше 1000 м.
  Ошибка — та же, что сообщает слияние: корень следа ковариации взвешенного пересечения, вес луча — его поперечная
  ошибка `дальность × сигма`.

Коды клеток: не слышно, одна станция (линия пеленга без точки), слепая геометрия (слышат две и больше, но лучи
почти параллельны — вдоль линии через две станции и между ними), точка с ошибкой.

`GET /api/v1/geometry/coverage?station_ids=17,18,19&range_m=1500&sigma_deg=3&height_m=150` — сетка (не больше
200 × 200 клеток) в метрах восток/север от `origin_lat/lon/alt` (по умолчанию — среднее станций) и доли площади.
На странице «Сопровождение» флажок «Слепые зоны расстановки» накладывает сетку для станций окна: зелёный — точка
(ярче — точнее), красный — слепая геометрия, серый — одна станция; дальность и высоту цели можно менять.

## 5. Проверки

`server/tests/test_acceptance.py`: синтетические испытания на сцене тестов слияния — две станции слышат проход
поршневого БПЛА и передают пеленги (через настоящий маршрут моста), третья в 700 м его пропускает, вертолёт проходит
далеко (не возможность), ложные тревоги после проходов и в тихий период, записи с тоном −40 дБFS при калибровке −20
дБFS. Проверяются Pd и интервал, дальность первой отметки с учётом задержки звука, классы, ложные тревоги и
станцио-часы, точность пеленга против заложенного шума (σ 1,5°), точки трека, уровни, исключения и окна работы,
совпадение ошибки клетки с ошибкой `bearing_fusion.intersect`, сетка, маршрут API и командная строка.

Сквозной прогон на поле станций-двойников (прошивка станций, мост, слияние, этот отчёт): `server/tools/twin_field.py`,
`docs/STATION_TWIN_FIELD_2026-10-01.md`.

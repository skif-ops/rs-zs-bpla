- Пароль `bench_viewer` перевыпущен, прежние сессии закрыты; полный вход через шлюз и приложение проверен до HTTP 303 на рабочую страницу.

## Правило обновления

После каждого развёртывания здесь фиксируются дата, версия, первые восемь символов commit, результат health check, состояние MQTT/TLS, результат миграции и путь к резервной копии. Запись выполняется в том же рабочем цикле, что и обновление сервера.

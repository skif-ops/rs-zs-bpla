# EVT-PRE-20: синхронизация прошивки станции и приложения монтажника

Дата: 05.10.2026.

Статус закупки: пакет EVT-PRE-20 Rev_D передан заказчику. Приведённые ниже
программные работы не отменяют и не блокируют заказ аппаратуры.

## Прошивка станции

Инженерная целевая сборка для `STM32U585VIT6Q` выполнена успешно на commit
`5a6429aac7040736be0019589a834ae0bba8c219`. Собраны ELF, BIN, HEX и map-файл.
Использовано 247216 байт flash из 1016 KiB, или 23,76%. Использовано 713896
байт RAM123 из 768 KiB, или 90,78%. Проверка stack usage прошла, максимальный
кадр 2304 байта у `zs_ed25519_verify` при разрешённом исключении до 2600 байт.

Сборка является неподписанной инженерной. Она подтверждает компилируемость
target-порта, но не разрешена для прошивки станций. До выпуска остаются secure
boot и A/B-разметка, ключи выпуска и подписанный манифест, прошивка на плату,
проверка периферии и связи, а также аппаратные и климатические испытания.

## Приложение монтажника

Локальные `testDebugUnitTest` и `assembleDebug` прошли на Gradle 9.6.0,
Android Gradle Plugin 9.4.0, API 36 и Build Tools 36.0.0. Полученный debug APK
имеет SHA-256
`9bef1139dcca1949475261d739205aac59bd440cdba559932fd928a1988bc5ba`.

Debug APK не является производственным выпуском. До выпуска остаются release
signing и SBOM, фиксация BLE UUID и bootstrap-протокола, проверка pairing и GATT
с реальным nRF52840, end-to-end проверка подписанного OTA и smoke-test на
телефоне Huawei без Google Mobile Services.

## Принятое разделение статусов

- закупка аппаратуры: передана заказчику, заказ не блокируется;
- исходники и инженерные сборки: PASS;
- производственная прошивка и release APK: открыты;
- стендовые проверки с собранной станцией: выполняются после получения плат.

Машиночитаемые доказательства находятся в
`firmware/targets/evt_pre_20/engineering_build_evidence.json` и
`android/debug_build_evidence.json`.

# Мухоед server v0.8.1

Дата приемки: 2026-09-04

## Основание

Версия выпущена после повторного анализа четырех новых полевых видеозаписей: `IMG_8704`, `IMG_8705`, `IMG_8707`, `IMG_8721`.

## Изменения

1. Добавлена узкополосная фильтрация стационарных гармоник сети 50 и 60 Гц до поиска гребенки двигателя. Это закрывает сценарий, в котором сеть 50/100/200 Гц могла быть принята за гармоники БПЛА через субгармоники 12.5, 16.7 или 25 Гц.
2. Добавлен адаптивный порог RMS для окон признаков. Он сохраняет тихие полезные окна, если одиночный короткий импульс завышает пиковую нормализацию записи.
3. Доверие к акустическому семейству теперь учитывает не только относительный отрыв победителя, но и абсолютное соответствие модели.
4. Результат семейства помечается как условный относительно независимого AIR gate. Без подтверждения воздушной цели эти четыре записи дают `UNKNOWN`.
5. Экспертные подсказки FP-1 и GR2 больше не могут автоматически стать рабочим типом. Они доступны только как исследовательская метаинформация.
6. В зависимости добавлен `httpx2`, а фикстуры БД сделаны повторяемыми для полного API-прогона.

## Приемка

- все четыре записи обнаружены в первом окне 0-2 с;
- положительны 94 из 96 двухсекундных окон;
- итоговый тип для всех записей: `UNKNOWN`;
- условное семейство для всех записей: `PROP_PISTON`, статус `provisional_family`;
- без AIR gate семейство для всех записей: `UNKNOWN`;
- полный регрессионный набор: 68 PASS, 0 FAIL;
- прежние шесть целевых записей не потеряли детекцию после сетевой фильтрации;
- природные фоновые записи остались отрицательными.

## Ограничения

- `PROP_PISTON` является исследовательской условной оценкой, а не подтвержденным типом;
- глобальный F0 на записях `IMG_8704` и `IMG_8705` неоднозначен из-за выбора порядка гармоники, поэтому его нельзя напрямую переводить в обороты;
- оценки числа роторов, лопастей и типа силовой установки остаются исследовательскими и не должны использоваться как рабочее решение;
- `TURBINE_JET` все еще не обеспечен достаточным обучающим материалом;
- новые записи нельзя включать в обучение до подтверждения типа, условий пролета и независимого источника метки.

# Правила ветвления проекта

## main

Содержит только срез, прошедший локальные проверки и CI. Прямые экспериментальные изменения сюда не вносятся. Текущий статус аппаратной части сохраняется OPEN, пока не выполнены физические испытания.

## develop

Интеграционная ветка. В ней объединяются проверенные feature-ветки, актуальный сервер «Мухоед», целевые профили станции, аппаратные таблицы, механические исходники, манифесты и проверочные результаты.

## evt

Ветка полного EVT изделия. Она не является инструкцией по сборке макетной станции. В нее входят общая программа испытаний, методики, формы протоколов и материалы gate для архитектуры 3+1.

## evt-mb

Ветка макетного EVT. Зафиксированы WeAct STM32U585CIU6, паяная перфоплата, разъемные жгуты, одна станция и один сервер для первого стендового этапа, развертывание Windows 11 и Ubuntu 24.04, а также сопряжение с «Мухоедом».

## Продвижение изменений

1. Feature-ветка проверяется самостоятельно.
2. Изменение включается в `develop`.
3. Для `develop` должны завершиться CI и проверка манифестов.
4. Проверенный SHA продвигается в `main` без изменения дерева.
5. Ветки `evt` и `evt-mb` получают только материалы своего вида испытаний.

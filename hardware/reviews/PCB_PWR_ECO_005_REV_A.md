## 6. Чувствительные цепи (раздел 3.3; замечание 9)

- **`SHUNT_LOAD_SENSE` / `SHUNT_SOURCE_SENSE`: обоснованное исключение из
  F_CU_PAIRED_QUIET_CORRIDOR / ZERO_VIA_TARGET.**
  - Шина `VBAT_SYS` шириной 3 мм идёт по F.Cu буквой Г (x = 39, y = 14…27; y = 27, x = 39…44; x = 44 вниз) и огибает U2. Шунт RSH1 остаётся снаружи. Поиск пути по растру F.Cu с зазором 0,2 мм пути не находит.
  - Пара проходит под шиной по B.Cu с шагом около 1,2 мм, у каждой линии RSH1 → U2 ровно два via: у шунта и у U2. Лишний третий via `SHUNT_SOURCE_SENSE` удалён.
  - Ответвления к TP2/TP3 начинаются у via на стороне шунта и идут парой с шагом около 2,2 мм.
  - Ни одна sense-линия не делит медь с током нагрузки: четырёхпроводная схема RSH1 сохранена.
- **`FB_3V8`: обоснованное исключение.**
  - Пути только по F.Cu между R1/R2 и U3.6 нет: вывод QFN с мелким шагом, узел SW и медь VIN.
  - Кратчайший реализуемый вариант с двумя via — 11,2 мм, текущий — 11,6 мм. Перетрассировка ничего не даёт.
  - Участок B.Cu длиной 3 мм под `SW_3V8` (F.Cu) целиком перекрыт сплошными плоскостями `GND_PWR` на In1 и In2. Без покрытия остаются только антиплощадки двух via (по 0,6 мм).
- **`RT_3V8`**: висячий via и отросток удалены (дельта 8); DRC больше не выдаёт `via_dangling`.

## 7. DFM, шелкография и библиотеки (раздел 3.4)

**Позиционные обозначения.** В стадии KiCad обозначения расставляются автоматически по точным
рамкам текста: не ближе 0,15 мм к площадкам, 0,1 мм к чужой шелкографии и 0,3 мм к краю платы.
Итог: 20 оставлены на месте, 42 перенесены при 0° или 90°, ни одно не скрыто. `silk_overlap`
уменьшилось с 16 до 0, предупреждения по обозначениям на меди — с 41 до 0.

**Адресная диспозиция 9 `silk_over_copper`.** Все 9 — графика шелкографии посадочных мест на
окнах маски; KiCad сообщает «Silkscreen clipped by solder mask»:

| Посадочное место | Элемент |

| RSH1 | полигон F.Silkscreen |

Графика остаётся в посадочных местах: правка разорвала бы паритет с библиотекой проекта. Gerber
пакета Review B выводятся с опцией «вычесть маску из шелкографии», поэтому на площадки она не
попадает.

**Библиотеки.** Решение принято по диффам, без обновления из стандартных библиотек. Проверка
паритета KiCad 9.0.9 (`drc_test_provider_library_parity.cpp`) сравнивает атрибуты, группы
перемычек, графику (прямоугольники нормализуются) и площадки, включая их ориентацию относительно

## 8. Формулировки зазоров (замечание 5)

- **Общая база 0,2 мм.** Зазор по умолчанию на всей плате 0,2 мм: в проекте нет классов цепей,
  действует значение KiCad по умолчанию. Это общее правило для всех объектов, а не локальное
  исключение из 0,3 мм. Расчётная база 0,3 мм (`PCB_PWR_ROUTING_AUTHORITY_REV_A`) не может быть
  выполнена у выводов с шагом 0,5 мм и оформлена как отклонение для EVT (запись применения 011).
- **Узлы SW.** Для `SW_3V8`/`SW_3V3` действует 0,4 мм (первое правило `PCB-PWR.kicad_dru`).
- **U3/U4 (LMR60440 RAK0009A).** Лимит 0,12 мм только между объектами одного посадочного места.
  Фактический минимум 0,125 мм (площадка 2 `GND_PWR` — выводы 6/7). Правило действительно только
  для внешней меди 1 oz.
- **U2 (VSSOP-10).** Лимит 0,19 мм только между объектами одного посадочного места. Фактический
  минимум 0,200 мм (площадка 2 `GND_PWR` — вывод 3 `FAULT`).
- Значения 0,125 и 0,200 мм измерены по площадкам кандидата. Проверка дорожек по общему
  минимальному зазору фабрики не заменяет проверку маски и трафарета соседних SMD-площадок; она
  остаётся за DFM при оформлении заказа.

## 10. Цепочка аудитов

ECO-005 признаётся как точный преемник 011: `is_eco_005()` проверяет совпадение байтов с
зафиксированным кандидатом, так же как `is_autoroute_011()`. Патч цепочки аудитов:

- добавляет SHA-256 ECO-005 рядом с SHA-256 011 во все наборы принятых плат аудитов 006–010,
  ECO-003 и 011;
- добавляет переопределение позы NT2 на 180° — единственное изменение размещения;
- обновляет в `PCB_PWR_CAPTURE_STATUS_REV_A.json` контрольные значения: семантический SHA-256
  и число медных элементов (873 → 842, зон по-прежнему 33).

Локально на итоговом дереве проходят все 103 шага PCB-PWR из `ci.yml` и `pcb-native.yml`, кроме
шагов с KiCad и регенерации схемы. Их проверяет CI.

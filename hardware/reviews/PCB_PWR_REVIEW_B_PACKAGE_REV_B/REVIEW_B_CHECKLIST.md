## Что проверить глазами

Координаты в мм, начало — левый верхний угол платы.

1. **Область J2/NT** (x 72…83, y 37…57):
   - поворот NT2;
   - зона `GND_DIGITAL` F.Cu 75,8…82,6 × 46,4…50,4;
   - три via `GND_MODEM` у NT1;
   - второй via `GND_MIC`;
   - via `GND_PWR` у NT1–NT3;
   - доменные земли соединяются с `GND_PWR` только через перемычки.
2. **Sense у RSH1/U2** (x 33…47, y 20…33): по два via на линию, пара по B.Cu под шиной `VBAT_SYS`,
   ответвления к TP2/TP3 от via у шунта.
3. **Шелкография** (`PCB-PWR_assembly.pdf`, `gerber/*SilkS*`): читаемость перенесённых обозначений,
   отсутствие шелкографии на площадках.
4. **Решения по исключениям**: sense-пара и `FB_3V8` (разд. 6 записи), 9 `silk_over_copper`
   (разд. 7), класс 3V3 1,0 / 0,35 А (разд. 5).

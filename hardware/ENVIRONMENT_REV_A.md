# Дионея EVT-PRE-20 Rev.A — environmental baseline

Статус: `LOCKED EVT RANGE / TEST EVIDENCE PENDING`
Основание: `DEC-019`, частично заменено решением `DEC-149`.

## 1. Температурный диапазон

- Рабочая температура окружающей среды для EVT: **−20…+60 °C**.
- Хранение и транспортирование выполняются в пределах подтверждённых диапазонов
  батареи, герметиков, мембран и материала корпуса; неподтверждённые крайние
  температуры не засчитываются как пройденные.
- Для последующей серийной квалификации сохраняется проектная цель **−40…+70 °C**
  и целевой паспортный диапазон компонентов не уже **−40…+85 °C**.
- Компоненты с более узким диапазоном допускаются в EVT только по зафиксированному
  исключению с проверкой работы в диапазоне EVT.

### 1.1. Исключение для EVT-PRE-20

Решением заказчика от 2026-10-19 минимальная температура для EVT принята равной
**−20 °C**. Требование −40 °C не блокирует изготовление и испытания EVT. Оно
сохраняется как цель серийной квалификации после EVT.

Для EVT используется только версия батареи `DIO-BAT-LFP-12V50-H-REV-A` со
встроенным подогревом. До зачёта холодного испытания должны быть подтверждены
пороги и гистерезис нагревателя, его ток и энергия, источник питания, запрет заряда
до прогрева ячеек, работа BMS и фактическая температура ячеек. Датчик Victron
`SBS050150200` с паспортным минимумом −10 °C остаётся принятым исключением EVT;
в интервале −20…−10 °C проверяется переход MPPT на внутренний датчик.

## 2. Горячий режим +60 °C для EVT

Испытание проводится на собранной станции в репрезентативном корпусе при +60 °C ambient. Проверяется worst-case realistic load. Испытание при +70 °C относится к последующей серийной квалификации.

- BG95 передача данных и reconnect/burst;
- GNSS/PPS;
- LoRa профиль RU868;
- BLE service/OTA window;
- запись/чтение NOR и microSD;
- четыре акустических канала, DSP и классификация;
- работа DC/DC PCB-PWR.

Для каждого тепловыделяющего узла фиксируются ambient, case/board temperature, ток, напряжение и оценка junction temperature. Нельзя считать компонент прошедшим только потому, что его datasheet имеет +85 °C предел: необходимо доказать отсутствие превышения внутреннего температурного предела с учетом self-heating.

## 3. Холодный режим −40 °C для последующей серийной квалификации

После стабилизации изделия при −40 °C проверяются:

- cold boot и повторные power cycles;
- программирование T5838 AAD через `AAD_CFG/THSEL`, AAD wake и переход в полный PDM capture;
- GNSS cold start/PPS и time-trust;
- cellular attach/recovery, если RF fixture позволяет;
- LoRa;
- BLE commissioning;
- NOR/microSD;
- USB service/recovery;
- разъёмы, кабели и отсутствие хрупкого разрушения/потери контакта.

## 4. LiFePO4

Рабочий диапазон станции и принятое исключение EVT **не означают разрешение заряда LiFePO4 при отрицательной температуре ячеек**.

- При температуре элемента ниже утверждённого порога заряд запрещён. Для принятой
  батареи поставщик указывает диапазон заряда 0…+55 °C; подогрев должен сначала
  вывести ячейки в разрешённый диапазон.
- Исключение допускается только для утвержденной батарейной системы с документированным heater/low-temperature charging algorithm и отдельным EVT.
- Разряд/питание станции при низкой температуре допускается только в пределах datasheet выбранной батареи/BMS.
- Температура для charge inhibit должна относиться к элементу/батарейному пакету, а не только к воздуху внутри корпуса.

## 5. Разъемы и кабели

- JST GH MIC connector исключен из Rev.A из-за несоответствия нижней температурной границе проекта.
- Первоначальный 5-contact Pico-Lock также superseded после выявления обязательного T5838 `THSEL` one-wire AAD configuration input.
- MIC Rev.A: Molex Pico-Lock 1.50 mm, **6 circuits**: header `5040500691`, housing `5040510601`, terminal `5040520098`, nominal operating range −40…+105 °C.
- MIC pin 5 = `MIC_WAKE`; pin 6 = shared `AAD_CFG/THSEL`.
- MAIN↔PWR Micro-Fit 3.0 остается допустимым по температуре, но требует pull/current/thermal validation.
- U.FL и готовые coax assemblies выпускаются только после проверки температурного диапазона **всей кабельной сборки**, не только board receptacle.

## 6. Механика и корпуса

Для vacuum casting, 3D-print fallback и будущего injection-molding source package отдельно подтверждаются при −40/+70 °C:

- отсутствие растрескивания, коробления и потери preload;
- работоспособность резьбовых вставок и крепежа;
- сохранение IP-уплотнения и вентиляционной мембраны;
- отсутствие блокировки акустических портов/мембран;
- отсутствие недопустимого изменения RF characteristics;
- кабельные вводы и strain relief.

Материал корпуса нельзя выпустить по одной комнатной FAI-проверке.

## 7. Release gate

Environmental gate считается закрытым только когда:

1. BOM/AVL не содержит деталей с неподходящим температурным диапазоном;
2. `EVT-ENV-COLD`, `EVT-ENV-HOT`, `EVT-ENV-CYCLE`, `EVT-ENV-BATT-COLD` имеют PASS;
3. thermal report содержит реальные температуры и режимы нагрузки;
4. холодный отчет содержит cold-start, `AAD_CFG/THSEL`, WAKE и connector/harness evidence;
5. выбранная батарея/BMS/MPPT имеет подтвержденные температурные правила;
6. изменение компонента, корпуса, кабеля или firmware power profile, влияющее на температуру, инициирует соответствующий retest.

# EVT-PRE-20 — повторный диагностический импорт PCB-PWR и PCB-MIC

Дата: 2026-10-14. Ветка: `evt-pre-20`. Altium Designer 26.10.1.5 Trial, KiCad Importer.

**NOT FOR MANUFACTURE.** Это реальные файлы Altium после повторного импорта двух плат из отдельных копий KiCad 9 с нормализованными числовыми ID слоёв. Исходные файлы в `hardware/kicad/native/` не менялись. Ранее ошибочно импортированные версии сохранены в `diagnostic-import/` для сравнения.

## Что исправлено

Таблица исходных KiCad 9 плат использовала `B.Cu = 2`, `F.Mask = 1`, `B.Mask = 3` и другие номера, которые Altium импортировал как внутренние слои. Скрипт [prepare_kicad9_layer_test.py](../prepare_kicad9_layer_test.py) создал полную копию дерева KiCad на F и изменил только числовые ID в таблицах слоёв PCB-PWR и PCB-MIC на схему, применённую в PCB-MAIN. Для PCB-PWR и PCB-MIC KiCad 10 повторил исходные DRC и schematic parity результаты: PWR 7 нарушений / 251 замечание parity; MIC 8 / 55.

При повторном импорте карта слоёв была проверена в мастере: `F.Cu → Top`, `B.Cu → Bottom`, `In1.Cu → Mid Layer1`, `In2.Cu → Mid Layer2` для PWR; маски, паста и шелкография указывали на соответствующие верхние/нижние слои; `Edge.Cuts → Keep Out Layer` по стандартному отображению Altium. Отдельно созданы `DioneyaPWR.PcbLib` (9 модулей KiCad) и `Dioneya.PcbLib` (2 модуля KiCad). Все ссылки `DocumentPath` в обоих `PrjPcb` относительны и разрешаются на файлы этого каталога: PWR 13/13, MIC 9/9.

Независимая сверка [verify_diagnostic_pcb.py](../verify_diagnostic_pcb.py) читает `Tracks6`, `Vias6`, `Nets6` и заголовки других потоков `PcbDoc`. Результаты: [PCB-PWR/verification.json](PCB-PWR/verification.json), [PCB-MIC/verification.json](PCB-MIC/verification.json).

## Что остаётся открытым

- Журналы импортера содержат `KiCadLib.PCB.PCBLine` errors: PWR 703, MIC 73. Все трассы с назначенными сетями перенесены, но прочая графика, контуры и специальные объекты не проверены поэлементно. Предупреждения PWR 2117, MIC 275 требуют разбора.
- Совпадение количества компонентов и площадок не доказывает `refdes–pin–net`, форму площадок, отверстия и ориентацию. `PcbLib` создана, но её соответствие установленным компонентам платы не подтверждено.
- KiCad содержит 33 зоны PWR, новый PcbDoc — 28 полигонов; различия не исследованы. MIC зон не содержит. Поля стеков, RF/power, контролируемый импеданс, DRC/compile Altium, варианты сборки и производственные выходы не проверены.
- Исходная база KiCad уже имеет нарушения DRC и schematic parity, перечисленные в [аудите](../EVT_PRE_20_KICAD_BASELINE_AUDIT_2026-10-14.md). `manufacturing_release=false` остаётся в силе.

`OutJob`, Gerber, drill, BOM, Pick&Place и производственный ZIP из этих файлов не выпускаются до закрытия перечисленных пунктов.

# PCB-MIC — первый Altium compile и batch DRC после импорта

Дата: 2026-10-14. Altium Designer 26.10.1.5 Trial. Проверялась копия из `layer-corrected-import/PCB-MIC/` на ветке `evt-pre-20`.

Владелец проекта выполнил **Validate PCB Project**; панель Messages показала `Compile successful, no errors found` в 16:02:41. Это наблюдение пользователя; отдельный файл отчёта компиляции Altium не создавался. Затем выполнен **Tools → Design Rule Check** с включёнными `Create Report File` и `Batch DRC → Used On`. Сохранены исходные файлы Altium без редактирования: [текстовый DRC](Design%20Rule%20Check%20-%20PCB-MIC.drc) и [HTML DRC](Design%20Rule%20Check%20-%20PCB-MIC.html).

## Что действительно осталось в исходной геометрии

KiCad использует для MK1 локальное правило `clearance ≥ 0,125 мм`, `hole_clearance ≥ 0,10 мм` в `hardware/kicad/native/PCB-MIC/PCB-MIC.kicad_dru`; общий зазор сети — 0,20 мм. Это правило не найдено в потоке `Rules6` Altium. В исходном KiCad DRC уже есть **8** ошибок около акустического отверстия: минимум около **0,0961 мм < 0,10 мм**. Импорт сохранил площадки и отверстие, поэтому этот дефект не исчезает при исправлении настроек Altium.

Отчёт Altium также показывает расстояния **0,191 мм** и **0,150 мм** от акустического отверстия до двух участков дорожки **GND**. В [производственном описании MIC](../../../../reviews/PCB_MIC_MANUFACTURING_HANDOFF_REV_A.md) исключение 0,10 мм разрешено только для площадки GND производителя вокруг акустического отверстия, **не для дорожки**; обычное требование для отверстия и меди — 0,20 мм. Эти два участка требуют отдельного инженерного исправления или документированного решения. Нельзя просто снизить общее правило до 0,096 мм.

## Следующие действия

1. В Altium перенести и проверить реальные проектные ограничения, включая локальное правило MK1, минимальные ширины и via. Зафиксировать политику тестовых точек по DFM/плану тестирования.
2. Осмотреть нулевой сегмент в Board region и исправить его, если он действительно присутствует в файле.
3. Согласовать коррекцию геометрии акустического отверстия / площадки MK1 и двух дорожек GND, сохранив требования производителя и инженерную базу. После изменения KiCad повторить импорт и все сверки.
4. Повторить batch DRC и сохранить отчёт. Текущий отчёт — базовая диагностика, **NOT FOR MANUFACTURE**.

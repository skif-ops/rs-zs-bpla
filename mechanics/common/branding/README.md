## Рельеф на корпусе (FDM, сопло 0,4 мм, `mechanics/3d_print/DESIGN_RULES.md`)

- Используется `…STACKED_MONO_RELIEF…`: звуковые волны и зазоры меньше ~0,5 мм
  (белая линия внутри лепестков) в нём не выводятся, иначе не пропечатаются.
- Ширина эмблемы не меньше 40 мм (тонкие элементы — не меньше ~0,7 мм);
  при этом логотип занимает около 48×44 мм. Ровная площадка под него — 52×48 мм.
- Рельеф 0,6 мм (выпуклый) или углубление 0,6 мм; масштаб по ширине, пропорции
  не менять.
- Цветные варианты — для печатной продукции и наклеек, не для рельефа.

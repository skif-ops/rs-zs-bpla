Дионея firmware core 1.2.0 EVT-MB

Принятая цель: WeAct STM32U585CIU6.
Аудио: 4 синхронных I2S-канала, SAI1_A master RX + SAI1_B synchronous slave RX,
32 кГц, 32-битные слоты, полезные 24 бита. PA8=BCLK, PA9=WS,
PA10=DATA_A (MIC1/2), PB5=DATA_B (MIC3/4).
Архив: microSD SPI, CS PA4. BG95: USART1 без RTS/CTS, AT+IFC=0.

Host core и encoder можно проверить CMake/CTest. Полная target-прошивка считается
собранной только после создания проекта STM32CubeIDE по инструкции ИНС-01 и привязки
HAL/DMA callback к API zs_audio_i2s. Готовый .bin в этот релиз не включён, потому что
физическая конфигурация CubeMX ещё не прошла аппаратный gate.

# EVT-PRE-20, профиль стендового выпуска Rev C

## Назначение

Профиль фиксирует комплект `EVT_PRE_20_BENCH_RELEASE_2026111201` для прошивки и аппаратных испытаний станции. Комплект содержит подписанные образы STM32U585 и nRF52840, а также подписанное APK приложения монтажника. Закрытые ключи, пароли, Android keystore и подписанное разрешение полевой передачи LoRa в комплект не входят.

Статус: `READY_TO_FLASH_HARDWARE_VALIDATION_PENDING`.

## Состав

| Компонент | Версия | Проверено без готового изделия | Что требует изделия |
|---|---:|---|---|
| STM32U585 | 2026111201 | Сборка, размер, подпись Ed25519, хеш образа | SWD, запуск, периферия, A/B, питание, RF и EOL |
| nRF52840 | 0.1.1+2026111201 | Воспроизводимая сборка, MCUboot ECDSA P-256, проверка подписи | BLE, UART IPC, serial recovery, обновление и откат |
| Приложение монтажника | 0.1.1-bench.20261112, code 2026111201 | Unit tests, release build, подпись APK | BLE на реальной станции и полный сценарий монтажа |

## Управление LoRa из приложения монтажника

В приложении монтажника реализован раздел `LoRa RU868`. Он доступен только при физическом сервисном режиме станции, защищенном BLE-соединении и роли инженера.

Приложение выполняет следующие операции:

1. Читает текущий режим, частоту, spreading factor, мощность, версию профиля и остаток времени радиотеста.
2. После подтверждения подключения согласованной нагрузки 50 Ом запускает радиотест на 5 минут.
3. Позволяет остановить радиотест досрочно. Прошивка в любом случае выключает его автоматически, не позднее чем через 15 минут или при выходе из сервисного режима.
4. Принимает файл подписанного полевого профиля и передает его станции. Станция самостоятельно проверяет подпись, версию, частоты, полосу, spreading factor, мощность, скважность и совместимость с установленной прошивкой.
5. Записывает локальный журнал операций LoRa в закрытое хранилище приложения.

Обычная настройка станции не может включить радиопередачу. Подписанный профиль разрешается выпускать после PASS электрического EOL, аппаратного самотеста STM32 и nRF52840, проверки RF-тракта, проводных RF-измерений, проверки установленной антенны, проверки протокола LoRa и подписания протокола испытаний. Для каждой станции обязателен индивидуальный EOL PASS.

После подтверждения испытаний повторная прошивка не требуется. Инженер устанавливает подписанный полевой профиль через приложение монтажника. До этого полевая передача остается выключенной, а испытательная передача доступна только в ограниченном сервисном режиме.

## Ограничения выпуска

Программные сборки и подписи не заменяют испытания готового изделия. Статус аппаратной проверки не закрыт. Не допускаются RDP Level 2, BOOT_LOCK, TrustZone, WRP, PCROP, отключение SWD, отключение BOOT0 recovery и запись неизменяемого производственного корня доверия.

Профиль производственной защиты выпускается отдельно после полного аппаратного PASS, утверждения численных EOL-пределов и полной регрессии. Блокировка конкретной станции разрешается только после ее собственного EOL PASS и повторной проверки запуска, связи и обновления.

## English summary

Release `EVT_PRE_20_BENCH_RELEASE_2026111201` is ready for flashing, while hardware validation remains pending. The installer application provides an engineer-only LoRa screen for status, a time-limited conducted RF test, signed field-profile installation and a local audit log. Field transmission is off by default. After the signed RF and EOL results are approved, the field profile is installed through the application without reflashing the station. Firmware locking remains forbidden until full target validation and per-station EOL PASS.

Журнал охватывает STM32U585, nRF52840, загрузчики, общий протокол и выпускной пакет станции. История до первого подписанного комплекта восстановлена по Git и техническим контрактам. Этапам без официальной версии номер задним числом не присваивается.

- Версия образа: `2026100601`.
- Подпись: Ed25519 над `DIO-FW-V1` и canonical CBOR manifest.

### nRF52840

- Target: `Raytac MDBT50Q-P1MV2 / nRF52840`.
- Версия: `0.1.0+2026100501`.
- Загрузчик: MCUboot, serial recovery, swap without scratch.
- Подпись: ECDSA P-256.
- SHA-256 подписанного приложения: `27a9e76b969ba6197de9b77874786a304dc0c04efe2f8994307fdc35560dd89b`.
- SHA-256 объединённого HEX: `7528e8a474283776162c9ac49d3de5082aa86a9a0d0f98d66603fdb2132a0f7f`.
- SDK: nRF Connect SDK `v2.7.0`.

### Функции выпуска

- Передача данных четырёх микрофонов 3+1, DSP, DOA/TDOA и разделение до трёх целей.
- BG95 MQTT/TLS, dual-SIM policy, защищённые команды, ротация ключа и application receipt.
- A/B обновление STM32 с trial boot и rollback; подписанное обновление nRF52840 через MCUboot.
- Атомарные журналы команд, outbox событий и архив аудио в общей NOR с раздельными erase blocks.
- Защита времени по GNSS/PPS с ограниченным сетевым fallback.
- Watchdog задач, причины перезапуска и маска зависших задач в heartbeat.
- Удалённая настройка сети с пробным применением и возвратом.
- Локальное BLE commissioning с физическим сервисным окном и контролем роли.

## Правило совместного выпуска

Версии STM32 и nRF52840 могут различаться, но производственный комплект получает единый `release_id`. Нельзя заменять один образ внутри выпущенного архива. Любая замена требует нового `release_id`, нового манифеста, новых SHA-256 и записи в этом журнале.

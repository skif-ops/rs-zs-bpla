# EVT-MB v1.3 — паяный стенд

Актуальный выпуск для первого цикла: одна станция DIO-EVP-001 на паяной макетной плате 70 × 90 мм и один сервер «Мухоед» под Windows 11 либо Ubuntu 24.04.

Состав выпуска:

- полный сборочный комплект: DOCX, открываемый XLSX, совместимые CSV, ПО станции и сервера, 3D-модели, монтажная схема и распайка;
- отдельный комплект ПМИ и отчётных материалов;
- макетная плата только с пайкой; разъёмные модули устанавливаются на впаянные колодки;
- четыре одинаковых I2S-микрофона одной партии;
- провода, сечения, разъёмы и ответные части заданы в РКД 24/25.

Восстановление архивов из каталога `releases/evt-mb/v1.3`:

```bash
../../reassemble.sh assembly_parts РС_Дионея_EVT_MB_v1_3_ПОЛНЫЙ_КОМПЛЕКТ_OPEN.zip
../../reassemble.sh report_parts РС_Дионея_EVT_MB_v1_3_ПМИ_И_ОТЧЕТНЫЕ_МАТЕРИАЛЫ_OPEN.zip
sha256sum -c ARCHIVE_SHA256.txt
```

Контроль выпуска: 46 структурных проверок PASS, 37 доступных серверных тестов PASS, C11 host-test PASS, CBOR 240 байт. Аппаратные проверки I2S/PPS/BG95/RF/S0-S4 имеют статус `NOT RUN` до сборки стенда.

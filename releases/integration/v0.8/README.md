## Контроль продвижения

1. Сформировать интеграционное дерево в отдельной ветке.
2. Выполнить локальные QG-1/QG-2, firmware CTest и server pytest.
3. Проверить CI интеграционной ветки.
4. Продвинуть тот же SHA в `develop` и повторить CI.
5. Продвинуть тот же SHA в `main` и повторить CI/Release integrity.

Любое последующее изменение дерева после проверки создаёт новую версию с новым SHA.

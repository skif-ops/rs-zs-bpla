# EVT-PRE-20 release candidate 2026101601

Подписанный комплект STM32, nRF52840 и промышленного Android APK для сборки EVT, прошивки DIO-EVT-B01, аппаратной характеризации и фиксации числовых EOL-пределов.

Статус: `SIGNED RELEASE CANDIDATE / HARDWARE QUALIFICATION PENDING`.

Комплект разрешён для EVT-сборки и измерений. Он не является окончательно квалифицированным серийным выпуском. Любой обязательный EOL-предел без утверждённого числового значения или без измерительного evidence формирует `HOLD`. Производственная блокировка STM32/nRF запрещена до полного аппаратного PASS и регрессии.

Закрытые ключи, keystore и пароли в каталоге и архивах отсутствуют. Контрольные суммы находятся в `SHA256SUMS.txt` каждого подкаталога и в `release_candidate_contract.json`.

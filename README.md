# Дионея / РС ЗС-БПЛА

Репозиторий распределенной акустической системы обнаружения БПЛА. Серверное ПО называется «Мухоед».

## Текущий проверенный baseline

- рабочая архитектура: гибридная станция и сервер;
- макетная станция EVT-MB: WeAct STM32U585CIU6, только паяный монтаж;
- микрофонная геометрия: 3+1, база 120 мм, верхний микрофон +150 мм;
- протокол информационного сопряжения: schema 1.4;
- сервер: Windows 11 или Ubuntu 24.04;
- документы и механика имеют статус OPEN до физических испытаний;
- аппаратный EVT не объявлен выполненным.

## Ветки

| Ветка | Назначение |
|---|---|
| `main` | Проверенный стабильный срез проекта |
| `develop` | Актуальная интеграционная рабочая база |
| `evt` | Материалы полноценного EVT, без макетной специфики |
| `evt-mb` | Материалы EVT на паяной макетной станции STM32U585CIU6 |

Подробные правила: [BRANCHING.md](BRANCHING.md).

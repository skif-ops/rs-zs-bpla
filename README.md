# Дионея / РС ЗС-БПЛА

Репозиторий распределённой акустической системы обнаружения БПЛА. Серверное ПО
называется «Мухоед».

## Текущий интеграционный baseline

Версия: `DIONEA-INTEGRATION-v0.13`, дата среза 17.09.2026.

- рабочая архитектура: гибридная станция и сервер;
- акустическая геометрия: четыре одинаковых микрофона, схема 3+1, база 120 мм,
  верхний микрофон +150 мм;
- протокол: редакция 1.4 с совместимой wire schema 3 и расширением телеметрии питания;
- сервер «Мухоед»: развёртывание на Windows 11 или Ubuntu 24.04;
- EVT-MB v1.3: одна станция на WeAct STM32U585CIU6 и паяной плате 70 × 90 мм;
- EVT-PRE-20 Rev.A: 20 станций на собственных PCB с `STM32U585VIT6Q` и
  аккумулятором-кандидатом RB40 40 А·ч;
- LoRa пилота: только RU868; UWB оставлен для перспективного развития;
- PCB-PWR: 12-контактный межплатный интерфейс и полноценный INA226 по I²C;
- RF-вывод: внешняя SMA bulkhead и внутренний U.FL–SMA пигтейл Taoglas `CAB.0243`;
- корпус пилотной партии: вакуумное литьё как основной вариант, 3D-печать как резерв;
- аппаратные результаты остаются `OPEN / NOT RUN` до сборки и сохранения первичных измерений.

## Ветки

| Ветка | Назначение |
|---|---|
| `main` | Проверенный стабильный интеграционный срез |
| `develop` | Интеграционная база, продвигаемая в `main` после CI без изменения дерева |
| `evt` | Материалы полноценного EVT без макетной специфики |
| `evt-mb` | Макетный EVT на паяной станции STM32U585CIU6 |
| `evt-pre-20` | Предсерийный EVT 20 станций на собственных PCB |

`evt-mb` и `evt-pre-20` остаются изолированными поставочными линиями. Их release/evidence
нельзя переносить друг в друга. В `main` и `develop` они представлены раздельными
каталогами и единым статусным реестром.

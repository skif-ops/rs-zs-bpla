# Этикетка станции: QR‑код v0.1

Статус: `IMPLEMENTED 2026-09-22 — server (muhoed-pki label-qr / label-sheet) + Android (сканирование в выборе станции)`.

## 1. Назначение

QR на корпусе каждой станции связывает физическое изделие с его записью в реестре «Мухоеда» и даёт
приложению установщика: серийник для фильтра BLE‑сканирования, tenant для экрана «Сервер» и
секрет первичного связывания (ICD BLE §2: «уникальный QR/секрет изделия»).

## 2. Полезная нагрузка

ASCII, одна строка, ~70 символов (QR версия 4–5, уровень коррекции M):

```
DIO1;S=<serial>;ID=<station_id>;T=<tenant>;K=<secret>;C=<crc>
```

| поле | значение |
|---|---|
| `DIO1` | версия формата |
| `S` | серийник пилотного состава: `DIO-EVT-001…040`, `DIO-EVT-B01` |
| `ID` | station_id: номер из серийника (1…40), стенд 901; должен совпадать с серийником |
| `T` | tenant по реестру: `pilot1` (лот 1), `pilot2` (лот 2), `bench` |
| `K` | секрет связывания: 16 случайных байт, base32 без `=` (26 символов A–Z, 2–7) |
| `C` | CRC‑16/CCITT‑FALSE (poly 0x1021, init 0xFFFF, проверочное значение `29B1` для `123456789`) по всему тексту до `;C=`, 4 hex‑символа |

Известный ответ (в тестах сервера и Android):
`DIO1;S=DIO-EVT-012;ID=12;T=pilot1;K=JBSWY3DPEHPK3PXPJBSWY3DPEH;C=C5A3`.

Приёмник отбрасывает строку при любом расхождении: CRC, версия, набор полей, серийник вне состава,
`ID` ≠ номер серийника, неверный алфавит `T`/`K`.

## 3. Секрет связывания

- Создаётся реестром при первой печати этикетки (`ensure_pairing_secret`) и хранится только в
  `registry.sqlite3` сервера (вне git); попадает в `station.json` пакета EOL (`pairing_secret_b32`), чтобы
  прошивка знала его для аутентификации телефона.
- В APK и в репозиторий не входит; приложение держит его только в памяти сеанса (intent), не сохраняет.
- Утеря/компрометация этикетки → `muhoed-pki pairing-secret-rotate <serial> --reason …`, перепечатать
  этикетку и перезалить пакет станции.
- Способ применения секрета в BLE (OOB‑данные LE Secure Connections или производный passkey) фиксируется
  на совместном прототипе с nRF52840 (ICD BLE addendum B.6).

## 4. Генерация

```
muhoed-pki label-qr DIO-EVT-012 --out labels [--png]     # DIO-EVT-012.svg + .txt (+ .png при Pillow)
muhoed-pki label-sheet --out labels/sheet.svg [--lot EVT-LOT-2] [--columns 4]   # лист A4
```
SVG самодостаточен (QR 30×30 мм + подпись «serial  id  tenant»), печатается в любом браузере/CorelDRAW;
для термопринтера — PNG. Команды входят в `muhoed-pki.exe`.

## 5. Сканирование

Android: экран «Выбор станции» → «Сканировать QR этикетки» (camera2 + ZXing core, без Play Services).
После распознавания серийник подставляется в фильтр, tenant — в экран «Сервер»; станция, чей `identity`
не совпадает с этикеткой, не подтверждается.

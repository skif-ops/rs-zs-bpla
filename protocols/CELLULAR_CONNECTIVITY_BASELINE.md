# Cellular connectivity baseline — EVT-PRE-20

## Решение для пилота

Для EVT-PRE-20 применяются только обычные SIM с публичным APN. Выделенный/private APN, статический IP и операторский API не применяются. Тариф не является входом или критерием EVT; технически проверяются регистрация в поддерживаемом RAT, передача данных, TLS и восстановление связи.

Пилотные профили создаются для МТС, МегаФон, Билайн, T2/Tele2 и SIM, предоставленной оператором ГЛОНАСС. Фактический underlying carrier, публичный APN и разрешённые RAT фиксируются для каждого ICCID.

## Сетевая модель

- станция всегда является инициатором соединения;
- основной транспорт — MQTT over TLS 1.2+;
- предпочтительный порт — 443, допустимый альтернативный — 8883;
- резерв — HTTPS over TLS через порт 443;
- входящие TCP/UDP-соединения к станции отсутствуют;
- работа за CGNAT обязательна;
- команды сервер → станция передаются через уже установленную MQTT-сессию;
- при недоступности сети события сохраняются локально с sequence/event_id и отправляются после восстановления связи;
- private APN отключён политикой пилота и не может быть выбран приложением или автоматикой;
- `PCB-MAIN` содержит два nano-SIM слота в режиме Dual SIM Single Standby;
- одновременно активна только одна SIM;
- переключение SIM выполняется только после штатного выключения BG95;
- профиль APN и слот могут меняться автоматически по ограниченной политике failover либо вручную через авторизованный BLE/mTLS канал.

## Параметры профиля SIM/APN

Конфигурация хранит: operator profile id, APN mode `PUBLIC`, APN, authentication mode, secret references при необходимости, preferred RAT, roaming policy, PIN policy, DNS policy, attach timeout, retry/backoff, номер слота и ICCID reference. Секреты не хранятся в GitHub.

Для каждой SIM разрешается несколько публичных профилей APN. Failover выполняется только между разрешёнными публичными профилями и двумя физическими SIM. Private APN является запрещённым значением конфигурации пилота.

Полные IMSI и ICCID считываются автоматически и включаются в compact heartbeat
на topic `status`. Передача разрешена только через MQTT с взаимным TLS. На
станции значения находятся только в оперативном состоянии, в открытые modem
logs не выводятся. Сервер сохраняет их во внутренней записи станции, а общий
station-list API возвращает только маскированные значения.

## Проверка после сборки станций

Операторские проверки и 24-часовой EVT PASS выполняются после сборки станций.
До фактического прогона соответствующие пункты имеют статус
`DEFERRED_UNTIL_STATIONS_ASSEMBLED / NOT RUN`.

1. Проверить регистрацию тестовой SIM каждого заявленного оператора во всех разрешённых RAT модема.
2. Проверить DNS и TLS к пилотному endpoint.
3. Проверить MQTT publish/subscribe не менее 24 часов.
4. Проверить восстановление после потери сети, питания и исчерпания PDP context.
5. Проверить фактическую доступность требуемого RAT и передачи данных; тарифные параметры не включать в критерии EVT.
6. Подтвердить доставку полного IMSI/ICCID в защищённом heartbeat, отсутствие
   идентификаторов в открытых логах и маскирование общего station-list API.
7. Проверить обе SIM в обоих слотах и подтвердить отсутствие зависимости результата от номера слота.
8. Выполнить не менее 100 циклов безопасного переключения слотов с чтением ICCID и восстановлением очереди.
9. Проверить автоматический и ручной переход между разрешёнными публичными профилями SIM1/SIM2, а также отказ при попытке включить private APN.

## Gate

Профиль получает `PASS` только после прикрепления modem log, server log, traffic counter и записи о восстановлении store-and-forward. До этого статус `OPEN / NOT RUN`.
